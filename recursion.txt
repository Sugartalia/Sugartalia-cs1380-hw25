ANSWERS

1. The base case is n <= 1 and it returns 1.
   The recursive part is n * factorial(n - 1). It keeps making n
   smaller until it gets to the base case.

2. If there wasnt a base case, the function would just keep calling
   itself forever. The stack keeps growing until it runs out of space
   and the program crashes (stack overflow).

3. Naive fib calls fib(n - 1) and fib(n - 2), but then those calls
   end up calculating the same numbers over and over again.
   Like fib(2) gets calculated alot when finding fib(10), which makes
   it get really slow.

4. The array gets smaller each time. It uses a + 1 and n - 1, so it
   checks one less element every call until n gets to 1.

5. A loop is better for a really big array because recursion makes a
   new stack frame for every element and could overflow the stack.
   A loop is also just simpler and faster for scanning an array.
